 This project implements a simulated messaging environment where users can draft, validate, and manage messages through a numeric menu interface.
 Key features include strict recipient number formatting (ensuring international codes), a 250-character limit for message text, and the automated 
 generation of unique 10-digit Message IDs and custom Message Hashes.
The codebase consists of three main components: Main.java, which handles the application loop and user inputs; Message.java, which contains the 
core logic for validation, ID/Hash generation, and simulated JSON storage; and MessageTest.java, a custom testing class that uses standard conditional logic
to verify that the application meets all specified functional requirements without relying on external testing frameworks.
